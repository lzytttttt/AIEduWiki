# AI辅助代码审查：代码质量与自我调节学习的脚手架

## 研究设计

两届学生（100+人，2023-2024）混合方法研究：
- GitHub PR中直接集成LLM-reviewer（human-in-the-loop）
- GitHub数据 + 反思报告 + 针对性调查

## 关键发现

### 量化
- 2024届产生更多迭代活动（1176 vs 581 PRs）
- 技术问题从2023年的227次AI失败降至0
- **响应率稳定**：32%（2023）和33%（2024）AI审阅后有后续提交

### 定性
- 学生使用LLM结构化评论聚焦审查
- 讨论代码质量
- 指导减少过度依赖

## 四大贡献

1. AI审阅者的 workflow 设计（scaffold learning + 缓解认知卸载）
2. 两届学生跨期对比
3. GitHub客观指标 + 学生自报告的混合方法
4. 负责任AI辅助审查的教学建议

## 核心结论

AI审查器可作为自我调节学习的有效脚手架，在不过度依赖的前提下提升代码质量意识。
