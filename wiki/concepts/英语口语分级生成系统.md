# 英语口语分级生成系统

> LLM根据学习者熟练度动态调整口语对话难度，实现K-12非母语英语学习者的个性化口语练习

## 核心问题

K-12非母语英语学习者在非沉浸式环境面临**熟练度不匹配**困境：
- 标准LLM对话太复杂，学习者无法跟上
- 需要教师实时调整语言复杂度

## 技术方案

### Proficiency-Aligned Framework

以**中国国家课程标准（CSE）**为代表性案例：

```
Learner Proficiency Level
         ↓
┌──────────────────────┐
│  Four-Tier Grading  │
│  System             │
└──────────────────────┘
         ↓
┌──────────────────────┐
│  Lexical Complexity  │
│  Controller          │
└──────────────────────┘
         ↓
   LLM-Generated Dialogue
```

### 核心资源

1. **分级词汇表**：按熟练度级别控制词汇选择
2. **多轮对话语料库**：支持不同场景的口语练习
3. **DDPO算法**（Diversity Driven Policy Optimization）：
   - 多轮GRPO方法
   - 保持对话多样性
   - 同时优化对话质量和教学价值

## 关键成果

- **低OOV率**（Out-of-Vocabulary）
- **高多样性**对话
- **自然性**和**教学价值**增强

## 贡献

- 为非沉浸式K-12学习者提供**可扩展口语练习平台**
- 框架可适配其他教育标准（非仅限于CSE）
