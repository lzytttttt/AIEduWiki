# Coursera

## 概述

Coursera 是一家美国在线教育平台公司，由 Andrew Ng 和 Daphne Koller 于 2012 年创立。平台与全球顶尖大学和机构合作，提供超过 7,000 门课程，覆盖数据科学、计算机科学、商业等多个领域。

## 关键事实与时间线

| 时间 | 事件 |
|------|------|
| 2012 | Andrew Ng 和 Daphne Koller 在 Stanford 创立 Coursera |
| 2013 | 获得 $22M 融资 |
| 2014 | 推出 Specializations |
| 2016 | 推出 Coursera for Business |
| 2017 | 推出 Coursera for Campus |
| 2019 | 用户突破 4500 万 |
| 2021 | IPO 上市（NYSE: COUR） |
| 2023 | 推出 AI 驱动的学习功能 |

## AI 教育应用

### 个性化推荐

Coursera 使用 AI 技术进行个性化推荐：

- **课程推荐**: 根据用户背景和目标推荐课程
- **学习路径**: 生成个性化学习路径
- **难度调整**: 根据用户水平调整课程难度

### AI 辅助功能

- **自动评分**: AI 驱动的作业自动评分
- **智能问答**: AI 驱动的课程答疑
- **学习分析**: 分析学习行为并提供反馈

## 与其他实体的关系

- **竞争关系**: 与 [Khan Academy](../entities/Khan-Academy/)、edX、Udacity 等竞争

- **市场定位**: 专注于高等教育和职业培训
