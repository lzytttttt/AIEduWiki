# Khan Academy

## 概述

Khan Academy 是一家美国非营利教育组织，由 Salman Khan 于 2008 年创立。其使命是为任何地方的任何人提供免费的世界级教育。平台提供超过 10,000 个视频课程和超过 100,000 道练习题，覆盖数学、科学、计算机科学、人文等多个学科。

## 关键事实与时间线

| 时间 | 事件 |
|------|------|
| 2004 | Salman Khan 开始为表亲制作数学辅导视频 |
| 2008 | Khan Academy 正式成立为非营利组织 |
| 2009 | 获得 Google 的 $2M 资助 |
| 2010 | 获得 Bill & Melinda Gates Foundation 支持 |
| 2012 | 用户突破 1000 万 |
| 2015 | 推出 Khan Academy Kids |
| 2018 | 推出 Khan Academy Districts |
| 2023 | 推出 Khanmigo（AI 辅导系统） |
| 2024 | Khanmigo 扩展到更多国家 |

## AI 教育应用

### 自适应学习系统

Khan Academy 的核心是其 [自适应学习系统](../concepts/自适应学习系统/)，通过以下方式实现个性化学习：

- **知识追踪**: 追踪学生对每个知识点的掌握程度
- **个性化推荐**: 根据学生水平推荐下一节课程
- **动态难度调整**: 根据答题表现调整练习难度

### Khanmigo（AI 辅导）

2023 年推出的 Khanmigo 是基于 GPT-4 的 [教学智能体](../concepts/教学智能体/)：

- **苏格拉底式教学**: 不直接给答案，而是引导学生思考
- **多学科支持**: 覆盖数学、科学、编程等
- **教师辅助**: 帮助教师生成教学计划和评估

## 与其他实体的关系

- **技术合作**: 与 OpenAI 合作开发 Khanmigo
- **资金支持**: 获得 Bill & Melinda Gates Foundation、Google 等支持
- **学术研究**: 与 Stanford、MIT 等大学合作研究
- **竞争关系**: 与 [Duolingo](../entities/Duolingo/)、[Coursera](../entities/Coursera/) 等平台竞争
