# 2021年：LLM 进入教育视野

> 2021 年，大语言模型（LLM）的能力开始被教育领域认真对待。GPT-3 的 API 开放后，教育科技公司开始探索 LLM 在教学中的应用。

## 年度概览

2021 年，LLM 从学术研究走向产品应用。教育科技公司开始测试 LLM 在作文批改、智能问答、个性化辅导等场景的效果。同时，知识追踪和自适应学习系统继续发展，多模态学习分析开始受到关注。

## 代表性工作

### 学术论文

- **Transformer-based Knowledge Tracing**: 基于 Transformer 的知识追踪模型性能超越传统 DKT
- **LLM for Education**: GPT-3 在教育场景的系统性评估
- **Multimodal Learning Analytics**: 结合视频、音频、文本的多模态学习分析

### 产品与平台

- **Grammarly**: 引入 GPT-3 增强写作建议
- **Quizlet**: AI 驱动的个性化复习计划
- **Squirrel AI**: 自适应学习系统在中国大规模部署

## 趋势总结

1. **LLM 产品化**: GPT-3 API 开放后，教育应用快速涌现
2. **知识追踪深度化**: Transformer 架构成为主流
3. **多模态融合**: 从单一文本到多模态学习分析
4. **个性化升级**: AI 驱动的个性化从推荐扩展到内容生成
