# LLM教学质量评估对齐

## 定义

研究 LLM 在生成教学材料（如前测题）时与人类专家的评估一致性问题，揭示 LLM 在教学质量判断上的系统性偏差。

## 研究背景

> **来源**: [arXiv:2606.23629](https://arxiv.org/abs/2606.23629)
> **日期**: 2026-06-21
> **主题**: LLM 生成前测题的教学质量评估 vs 人类专家评估

## 核心问题

设计有效的前测题（pretest questions）极具挑战：高质量问题需要 carefully 校准开放性、认知深度、与学习目标的对齐。LLM 能否 at scale 生成此类题目？其评估与人类专家是否一致？

## 核心贡献

- 系统评估 LLM 在教学设计任务中与人类专家的对齐程度
- 揭示 LLM 在判断教学质量时的系统性偏差模式
- 为 LLM 辅助教学设计提供改进方向

## 与现有概念的关联

- [[教育合成数据基准]] — LLM 生成教学内容的质量评估
- [[自动选择题生成]] — LLM 生成前测题属于自动化评估范畴
- [[知识追踪]] — 前测题质量直接影响知识状态诊断
- [[教育公平与偏见]] — LLM 的系统性偏差可能影响不同群体

## 开放问题

- LLM 在哪些认知层次（Bloom's Taxonomy）的评估偏差最大？
- 不同 LLM（GPT-4 vs Claude vs 开源模型）的偏差模式是否不同？
- 如何建立自动化的教学质量校准流程？
